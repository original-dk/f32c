# F32C Python 串口驱动

根据用户提供的 WHEELTEC F32C STM32F1 位置闭环、速度闭环例程及 TI 云台例程整理。电脑通过 **USB 转 TTL 串口模块**直接控制电机，不需要 STM32、Keil 或 ST-Link。

> 当前版本已通过协议与虚拟串口自动测试，但尚未连接真实 F32C 电机联调。首次上电请先运行“只读反馈”示例，再做小角度、低速度运动测试。

## 1. 已实现功能

- 使能、失能；
- 速度、多圈位置、单圈位置模式设置；
- 速度控制，单位 RPM；
- 多圈位置控制，单位度，底层为有符号 32 位、0.1° 分辨率；
- 单圈位置控制，范围 0.0～359.9°；
- 加速度设置；
- 速度、多圈角度、单圈角度、加速度、电压反馈请求与解析；
- 保存参数、多圈角度清零、单圈零点设置、修改地址、恢复出厂设置命令；
- BCC 校验、噪声丢弃、错误帧重新同步、任意串口分片接收；
- 同一总线多电机地址支持及反馈超时处理。

## 2. 接线

```text
电脑 USB
   │
USB 转 TTL 模块                 F32C 电机总线
   TX  ───────────────────────→  电机 RX
   RX  ←───────────────────────  电机 TX
   GND ─────────────────────────  GND
                                  │
                         地址 0x01：yaw 电机
                         地址 0x02：pitch 电机
```

- 串口参数：**115200、8 数据位、无校验、1 停止位、无流控**。
- 两台电机可按电机手册的多电机级联方式共用一条总线，地址必须不同。
- 电机、电机电源和 USB 转 TTL 模块必须共地。
- 必须使用 **TTL 串口**，不能直接接传统 RS-232 电平接口；TTL 电平和电机供电以电机手册为准。
- 不要用 USB 转 TTL 模块给电机供电，不要热插拔。
- 首次测试应固定云台，卸载或妥善支撑负载。电机失能后，云台可能因重力下落。

## 3. 安装

需要 Python 3.9 或更高版本。在本目录打开终端：

### Windows

```bat
py -m pip install -e .
py examples\list_ports.py
```

### Linux / macOS

```bash
python3 -m pip install -e .
python3 examples/list_ports.py
```

安装命令会同时安装唯一的外部依赖 `pyserial`。如果不希望以可编辑模式安装，也可以执行 `python -m pip install .`。

## 4. 第一步：只读反馈，不运动

将 `COM5` 换成实际串口：

```bash
python examples/read_angles.py --port COM5 --address 1 2
```

该程序只请求多圈角度和电压，**不会使能电机，也不会发送位置或速度命令**。若超时，依次检查：

1. 串口是否选错；
2. TX/RX 是否交叉连接；
3. 是否共地；
4. 电机是否已上电；
5. 电机地址是否确实为 1、2；
6. 波特率是否为 115200。

## 5. 第二步：双轴小角度运动示例

确认机械安全后，以下命令让 yaw 相对当前位置增加 10°、pitch 减少 5°：

```bash
python examples/two_axis_position.py --port COM5 --yaw-delta 10 --pitch-delta -5 --speed 20 --hold-time 5 --confirm
```

- 示例先读取当前多圈绝对角度，再计算相对目标，避免直接把当前位置误认为 0°。
- 与云台绘图例程一致，使用**多圈位置直通模式 `0x0003`**，先以当前位置为目标，再周期重发运动目标。
- 到位后默认继续保持 5 秒并打印反馈，然后退出并失能。可用 `--hold-time 10` 延长观察时间；`--hold-time 0` 表示一直保持，直到按 Ctrl+C。`--timeout` 只限制首次到位前的等待时间，进入保持状态后，反馈波动不会重新触发该超时。
- `--command-period 0.02` 表示目标重发周期为 20ms；没有特殊原因可先保持默认值。
- 退出、异常或键盘中断时，程序会尝试失能两台电机，因此保持时间结束后云台可能回落或失去保持力矩。
- `--confirm` 是人为安全确认开关；不加时程序拒绝运动。
- 初次测试建议把两个角度变化量进一步减小，并确保随时可以切断电机电源。
- 若只需检查上轴，可设 `--yaw-delta 0`，让下轴保持原位，只给 `--pitch-delta` 一个安全的小角度。

## 6. 在自己的程序中调用

只读取角度：

```python
from f32c import F32CBus

with F32CBus("COM5") as bus:
    yaw = bus.motor(1)
    pitch = bus.motor(2)
    print("yaw:", yaw.read_angle(), "°")
    print("pitch:", pitch.read_angle(), "°")
    print("电压:", yaw.read_voltage(), "V")
```

多圈位置控制的基本顺序：

```python
from f32c import F32CBus, Mode

with F32CBus("COM5") as bus:
    motor = bus.motor(1)
    motor.enable()
    motor.set_mode(Mode.MULTI_POSITION)
    motor.set_speed(20)                 # RPM
    current = motor.read_angle()        # 多圈绝对角度，单位：度
    motor.set_angle(current + 5.0)      # 相对当前位置增加 5°
    # 实际应用应在这里等待到位，并处理异常。
    motor.disable()
```

注意：`set_angle()` 接收的是**多圈绝对目标角度**，不是相对增量。上面的示例通过 `current + 5.0` 实现相对运动。

## 7. 协议摘要

命令帧：

```text
0x7A | 电机地址 | 命令字 | 数据区（可为空） | BCC | 0x7B
```

BCC 是从帧头 `0x7A` 到数据区末尾所有字节的逐字节异或。多字节整数均为大端序。

| 功能 | 命令字 | 数据区 |
|---|---:|---|
| 设置模式 | `0x00` | 2 字节无符号模式值 |
| 设置速度 | `0x01` | 2 字节有符号 RPM |
| 多圈位置 | `0x02` | 4 字节有符号角度，单位 0.1° |
| 单圈位置 | `0x03` | 2 字节无符号角度，单位 0.1° |
| 失能 | `0x05` | 无 |
| 使能 | `0x06` | 无 |
| 设置加速度 | `0x07` | 2 字节，转/s² |
| 保存参数 | `0x08` | 无 |
| 多圈角度清零 | `0x09` | 无 |
| 单圈绝对角度置零 | `0x0A` | 无 |
| 恢复出厂设置 | `0x0B` | 无 |
| 设置地址 | `0x0D` | 1 字节新地址 |
| 请求反馈 | `0x0E` | 1 字节反馈类型 |

模式值：速度 `0x0000`、多圈位置规划 `0x0001`、单圈位置规划 `0x0002`、多圈位置直通 `0x0003`、单圈位置直通 `0x0004`。

反馈类型：速度 `0x00`、多圈角度 `0x01`、单圈角度 `0x02`、加速度 `0x03`、电压 `0x04`。反馈帧固定为 9 字节，数据区为 4 字节；按例程，速度/加速度取低 16 位有符号值，单圈角度/电压取低 16 位无符号值，多圈角度取完整 32 位有符号值。电压换算单位为 0.01V，角度换算单位为 0.1°。

清零、置零、改地址、保存和恢复出厂设置会改变电机状态或参数，不要在未知当前配置时随意调用。本驱动不会在普通运动中自动调用这些命令。

## 9. 例程核对说明

- 使能帧、反馈请求帧已与 STM32F1 例程中的固定字节数组逐字节核对。
- 命令字、失能、清零、地址及完整反馈类型来自 TI 例程中的 `DataScope_DP.C/.h`。
- STM32F1 速度闭环示例的模式数组下标写法与位置闭环及 TI 通用协议实现不一致；本驱动采用后者，即 `0x00` 命令携带 2 字节模式值。
- PDF 提到的 `0x11/0x12` 位置环 PI 参数命令，在这三个通用协议实现中没有完整代码可供交叉核对，因此本版本未擅自封装。底层 `send_command()` 可在确认协议后用于扩展。
